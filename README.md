# tsoup!
## Physical board games. AI opponents. Your next game night.


Keep the board, the cards and the pieces. Let AI take the other side.


tsoup! is a free Windows app for playing physical board games with AI opponents. Share the game through photos or a web camera, talk through your moves, and move the pieces for both sides.


[Explore tsoup! →](https://tsoup.pages.dev/)

[Download tsoup! for Windows](https://github.com/1000Flies/tsoup/releases/tag/v0.8.0)

Under **Assets**, choose **tsoup-0.8.0-setup.exe**.


## Download prepared games


The app and its game packages are separate downloads. A fresh installation starts with an empty Library.


[Download prepared games](https://github.com/1000Flies/tsoup-games/releases/tag/prepared-games-tsoup%21)


1. Open **Assets** and download the **.tsoup** file for your game. Ignore the automatic **Source code** downloads.
2. In tsoup!, open **Library → Import package** and select the file.
3. Review the preview and choose **Import / update games**. Check the game's notes and included expansions before starting a match.


Prepare once, play again: imported ready rules can be reused for future matches. If your game isn't listed, you can prepare it inside the app.


These are prepared rules packages for playing with your physical board game, not digital versions of the games.


### Get started
1. Download and install tsoup! from [Releases](https://github.com/1000Flies/tsoup/releases/tag/v0.8.0).
2. Choose a game already in your library or import a prepared game package. If yours isn’t available, prepare it from its rulebook, adding any missing game information.
3. Connect a tablet as your controller and set up a fixed web camera for comfortable play. Use the tablet’s built-in microphone to dictate updates. A phone can also handle controls and handheld photos for a simpler first try.
4. Start a match. You’ll discover the rest as you play—the built-in guide is there whenever you need it.


Game preparation is done once. Reuse your package for future matches, and share it so someone else can get straight to playing.


### What you need
- A Windows PC.
- Your physical board game.
- Recommended: a tablet controller with its built-in microphone for dictation, and a fixed web camera above the board. An ordinary web camera is a good starting point; add cameras for private cards only when needed. For a simpler first try, one phone can handle both controls and handheld photos. No separate microphone is required.
- Your own paid ChatGPT or Claude account, currently supported.


**tsoup! is completely free. Your AI opponents use your own account’s allowance.** A paid subscription alone does not guarantee enough usage for a full match. In testing so far, entry-level paid plans have run short; the model and plan you choose matter.


Windows and Android have been tested. iPhone and iPad support is in beta and remains untested on real devices.


### Still exploring
tsoup! has grown through hands-on testing across different games. This first public beta opens that exploration to more players, setups and ideas. Compatibility and opponent quality will vary by game and AI model.
